# 截图目录（占位）

本目录用于存放面向公众的界面截图。当前仓库**还没有提交任何截图**，根目录 `README.md` 只链接到这里，不嵌入图片，避免出现失效图。

维护者补充截图后，请同时更新根 `README.md` 的「截图」一节。

## 计划中的文件

| 文件名                  | 内容                                     |
| ----------------------- | ---------------------------------------- |
| `home.png`              | 启动页 / 主界面（浅色主题）              |
| `instances.png`         | 实例库与实例卡片                         |
| `download-vanilla.png`  | PCL 式下载：「版本 → 加载器 → 具体版本」 |
| `custom-background.png` | 全窗口玻璃背景与自定义背景设置           |
| `lab.png`               | 实验室工具总览（7 个工具）               |
| `settings.png`          | 设置分组页                               |

## 规范

- 使用 PNG，建议 1440×900 或更高，保持 16:9；单张尽量小于 500 KB，可用 `pngquant` / `oxipng` 压缩。
- 覆盖浅色主题为主，深色 / OLED 可另加 `*-dark.png`。
- 截图前移除账号名、令牌、本机路径、服务器地址等隐私信息；不要使用真实用户数据。
- 临时文件（草稿、裁剪中间产物）请用 `*.tmp` 命名，仓库已忽略 `docs/screenshots/*.tmp`。
